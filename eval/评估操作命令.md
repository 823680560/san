# 评估操作命令

## 环境准备

```bash
# 确保在项目根目录下执行
cd C:/san
```

---

## 一、完整评估流程（推荐）

按顺序执行：**构建数据集（含 LLM 过滤）→ 检索评估 → 生成评估 → 生成报告**

```bash
python eval/main_evaluation.py
```

---

## 二、分步执行

### 1. 仅构建数据集

```bash
python eval/main_evaluation.py --only-dataset
```

### 2. 仅执行检索评估

```bash
python eval/main_evaluation.py --skip-dataset --only-retrieval
```

### 3. 仅执行生成评估

```bash
python eval/main_evaluation.py --skip-dataset --only-generation
```

### 4. 指定知识库（与 `--only-*` 配合使用）

```bash
# 仅对 project 知识库做生成评估
python eval/main_evaluation.py --only-generation --kb-name project

# 仅对 law 知识库做检索评估
python eval/main_evaluation.py --only-retrieval --kb-name law

# 仅构建 project 知识库的数据集
python eval/main_evaluation.py --only-dataset --kb-name project
```

`--kb-name` 可选值：`law` / `project`。不指定则处理所有启用的知识库。

注意：`--kb-name` 仅在 `--only-*` 模式下生效，完整评估模式下忽略此参数。

---

## 三、跳过特定步骤

### 跳过数据集构建（使用已有数据集）

```bash
python eval/main_evaluation.py --skip-dataset
```

### 跳过检索评估

```bash
python eval/main_evaluation.py --skip-retrieval
```

### 跳过生成评估

```bash
python eval/main_evaluation.py --skip-generation
```

### 组合跳过

```bash
# 仅构建数据集，不做评估
python eval/main_evaluation.py --skip-retrieval --skip-generation

# 使用已有数据集，直接做评估
python eval/main_evaluation.py --skip-dataset
```

---

## 四、使用自定义配置文件

```bash
python eval/main_evaluation.py --config ./eval/knowledge_base_config.yaml
```

---

## 五、输出文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `eval/datasets/law_eval_dataset.json` | 法律知识库评测集 |
| `eval/datasets/project_eval_dataset.json` | 项目知识库评测集 |
| `eval/reports/law/` | 法律知识库评估报告 |
| `eval/reports/project/` | 项目知识库评估报告 |
| `eval/reports/summary/` | 汇总对比报告 |
| `eval/reports/evaluation.log` | 评估日志 |

---

## 六、典型使用场景

### 场景1：首次完整评估

```bash
python eval/main_evaluation.py
```

### 场景2：已有数据集，重新评估

```bash
python eval/main_evaluation.py --skip-dataset
```

### 场景3：仅重新生成数据集

```bash
python eval/main_evaluation.py --only-dataset
```

### 场景4：单独测试 project 生成效果

```bash
python eval/main_evaluation.py --only-generation --kb-name project
```

此命令会加载已有的 `eval/datasets/project_eval_dataset.json`，执行 RAG 和 LLM Only 双模式评估，报告保存到 `eval/reports/project/` 和 `eval/reports/summary/`。

### 场景5：单独测试 law 检索效果（对比 top_k）

```bash
python eval/main_evaluation.py --only-retrieval --kb-name law
```
